🌿 Chloroplast ASCII Logo Alignment Fix

Problem: The ASCII logo had a hardcoded version "0.0.0.0" that was replaced with the actual version using a simple string replacement. This caused misalignment when the version number length differed from the original.
Solution: Implemented adaptive padding that centers the version text within a fixed-width area (30 characters), maintaining the logo's shape regardless of version string length.
